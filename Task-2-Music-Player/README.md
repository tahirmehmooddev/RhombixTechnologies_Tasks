## Overview
A responsive browser-based music player with a searchable track library, category filters, a queue and playback controls. The demonstration compositions are synthesized in the browser with the Web Audio API.

## Features
- Play and pause, next and previous track controls
- Search the music library and filter by mood/category
- Track queue and current-track display
- Shuffle and repeat modes
- Playback progress and seek control
- Volume control
- Responsive desktop and mobile layout
- Original generated instrumental demo patterns; no external audio files or music service are required

## Run locally
1. Open this project folder.
2. Open index.html in a modern browser.
3. Choose a track and press Play. Your browser may require a user interaction before audio can start.

## Project files
- **index.html** — player structure
- **style.css** — responsive light-blue and navy interface
- **script.js** — library, playback controls and Web Audio synthesis

## Audio note
Demo tracks are generated live by JavaScript using the browser's Web Audio API. They are not pre-recorded MP3/WAV files. Audio playback requires a browser that supports Web Audio.
