# Month 2 — Music Player

Owner: Tahir Mehmood

Internship: Rhombix Technologies — Web Development

Theme: White / Light Blue / Navy Blue

## Features
- Web-based music player
- Playlist functionality
- Music search
- Music categorization
- Play and Pause controls
- Next and Previous track controls
- Volume control
- Shuffle and Repeat
- Playback progress control
- Responsive design

## Technologies
- HTML5
- CSS3
- JavaScript

## Run Locally
1. Download or clone the repository.
2. Open the Month-2-Music-Player folder.
3. Open index.html in a modern browser.
4. Select a track and press Play.
